# Project Rules for ALFRED

- Preserve the 4-pillar architecture: supervisor, router, memory, tool registry.
- Never remove the 12 named agents or replace proper names with codes.
- Alfred must always address the user as `Jefe Maestro`.
- Do not claim real actions were executed unless the corresponding handler actually ran.
- Keep Spanish/English bilingual support intact.
- Run `npm run lint`, `npm run build`, and `npm run smoke` before delivery.
